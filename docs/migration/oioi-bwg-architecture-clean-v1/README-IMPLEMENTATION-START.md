# oioi-bwg 구현 착수 기준

이 디렉터리의 active 00~12와 Domain이 구현 기준이다. 계획·감사·미래 제안은 이 기준을 자동 대체하지 않는다.

1. [문서 안내](../../README.md)와 [WORK](../../WORK.md)에서 현재·보류 범위를 확인한다.
2. [인덱스](00-document-index.md)·[헌법](01-architecture-constitution.md)·해당 영역 문서와 결과를 읽는다.
3. 최신 원격 기준·작업 폴더·PR 상태를 확인하고 승인된 한 concern만 진행한다.
4. 구현이 active 계약과 충돌하면 영향받는 문서를 먼저 같은 변경 단위에서 개정한다.

P06 A~F는 [최종 결과](../implementation/console-guide-editor/P06-RESULT.md)로 종료했다.
P07~P10은 미착수이며 다음 기능의 상세 범위는 [설계](../implementation/console-guide-editor/DESIGN.md)와
[로드맵](../implementation/console-guide-editor/ROADMAP.md)에 있다. 이 안내 자체는 착수 지시가 아니다.

이전 M0 inventory·M1 runtime normalization 시작 지시는 당시의 이력이며 새 세션에서 반복하지 않는다.
전체 M0~M9 완료 여부는 단계별 근거로 판단한다. 종료 시 WORK·결정·결과·후속 연결을 갱신한다.
