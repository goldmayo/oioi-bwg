# 서비스 철학과 문구·톤 기준

어이어이바위게(OiOiBawige)의 서비스 태도, 캐치프레이즈, 화면 문구와 말투를 관리합니다.
2026-10-26 사용자와 확정한 기준이며 이후 사용자·관리자 화면과 소개 문구를 작성할 때 참조합니다.
문구 변경 담당자는 화면 작업 때 이 기준을 확인하고, 서비스 태도나 기준 문구의 변경은 사용자 결정에 맞춰 갱신합니다.

이 문서는 표현 기준을 소유합니다. 도메인 분류·권한·생명주기는 [Domain](migration/DOMAIN_SPECIFICATION.md),
UI 다국어와 콘텐츠 번역의 경계는 [Content/i18n 계약](migration/oioi-bwg-architecture-clean-v1/11-content-i18n-assets-runtime-architecture.md)을 따릅니다.
화면 동작과 P07 적용 상태는 Domain과 해당 구현 결과를 따르며, 이 문서만으로 구현 완료를 판단하지 않습니다.

## 1. 서비스의 태도

각자의 자유로운 응원을 존중하며, 함께 외치는 부분을 알면 공연을 더 재밌게 즐길 수 있도록 돕습니다.
팬들 사이에서 자연스럽게 생겨난 응원을 참고하고 자기 방식으로 즐길 수 있는 안내를 제공합니다.

**캐치프레이즈**

> 응원은 자유롭게, 조금 알면 더 재밌게.

**이용 안내**

> 함께 외치는 부분을 참고해, 편한 방식으로 즐겨 주세요.

## 2. 용어와 출처 표시

| 항목 | 기준 |
| --- | --- |
| 한국어 명칭 | 응원법 |
| 영어 명칭 | Cheering Guide |
| 공연 종류의 화면 이름 | 콘서트 / 페스티벌 |
| 출처 표시 | 공식 / 팬덤 |
| 공식 설명 | 공식 응원법이에요. |
| 팬덤 응원법 설명 | 팬들 사이에서 자연스럽게 생겨난 응원법이에요. |

팬덤 응원법은 팬덤에서 생겨난 다양한 응원을 참고할 수 있게 소개합니다. 단일 작성자의 제작물로만 설명하거나
모든 팬이 같은 방식으로 응원해야 한다는 의미를 부여하지 않습니다.
공식 표시는 해당 응원법의 출처를 나타냅니다. 참고용 공식 영상이 연결되어 있어도 팬덤 응원법의 출처 표시는 유지합니다.

영어 명칭의 공식 사용 예시는 [QWER CEREMONY 응원법 영상](https://www.youtube.com/watch?v=vqfSealefyQ)에서 확인할 수 있습니다.

## 3. 말투와 표현 원칙

- **자유를 존중합니다.** 함께 즐길 부분을 제안하고 선택의 여지를 남깁니다. 응원법을 정답·규칙·필수 행동처럼 표현하지 않습니다.
- **현장에서 쓰는 말을 씁니다.** 네임콜·떼창처럼 팬들이 실제로 사용하는 표현을 문맥에 맞게 씁니다.
  구체적인 응원 방식을 설명할 수 있을 때 추상적인 수식어나 두루뭉술한 설명으로 늘리지 않습니다.
- **짧고 친근하게 안내합니다.** 사용자 화면의 설명·상태·결과는 기본적으로 해요체를 씁니다.
  과장이나 억지 친밀감보다 사용자가 지금 알아야 할 내용을 먼저 전합니다.
- **관리 작업은 정확하게 안내합니다.** 관리자 화면의 설명·결과는 합니다체를 쓰고,
  버튼은 실제 행동을 나타내는 짧은 표현으로 씁니다. 초안 저장과 공개의 결과를 구분합니다.
- **실패는 차분하게 설명합니다.** 실패한 일과 가능한 다음 행동을 알려줍니다.
  편집 내용의 보존 등 상태를 약속하는 문구는 실제 동작이 보장할 때 사용합니다.

| 상황 | 기준 문구 |
| --- | --- |
| 관리자 저장 도움말 | 저장한 초안은 공개되지 않습니다. |
| 관리자 완료 안내 | 초안을 저장했습니다. |
| 관리자 버튼 | 초안 저장 / 미리보기 / 공개하기 / 공개 중단 |

## 4. 확정한 사용자 화면 문구

| 항목 | 문구 |
| --- | --- |
| 콘서트 설명 | 네임콜부터 떼창까지, 응원법을 함께 즐겨요. |
| 페스티벌 설명 | 쉽게 따라 할 수 있는 네임콜과 떼창 위주로 즐겨요. |
| 원본 링크 | 원본 보기 |
| 가이드 영상 링크 | 응원법 영상 보기 |
| 공유 버튼 | 링크 복사 |
| 복사 완료 | 응원법 링크를 복사했어요. |

종류별 설명은 도움말에 두고, 곡 화면에서는 등록된 원본·영상 링크를 먼저 보여줍니다.
2026-10-27 확정 시안에 따라 원본 링크는 출처 배지에서, 가이드 영상 링크는 재생 아이콘에서 제공합니다.

## 5. 다국어 문구 작성

영어 명칭은 Cheering Guide로 유지하고, 네임콜·떼창 등은 각 언어에서 같은 활동을 이해할 수 있도록 옮깁니다.
문장은 번역할 때 어순과 어조를 조정할 수 있도록 완성된 메시지 단위로 관리합니다.
UI와 곡별 설명의 다국어 작업은 P10 이후 범위입니다. 가사 번역·독음은 이번 범위에 포함하지 않습니다.
번역 계약은 Content/i18n 문서를 따릅니다.

## 6. 기존 About·Footer 제안 보존

아래는 2026-03-08 문서에 있던 소개·면책 제안 원문입니다. 이번 톤 확정과 구분해 보존하며,
실제 화면 반영 여부와 현재 소개·면책 문구의 확정 근거로 사용하지 않습니다.

사용자가 느낄 수 있는 심리적 거부감을 해소하고 법적/사회적 오해를 방지합니다.

### ① 메인 메시지 (About)

메인 페이지 또는 적절한 위치에 다음 메시지를 노출하여 프로젝트의 진심을 전달합니다.

> "친구들과 콘서트에서 더 즐겁게 놀고 싶어서 시작한 개인 프로젝트입니다. 이 가이드가 누군가의 응원을 제한하기보다, 처음 응원하는 분들에게 작은 힌트가 되길 바랍니다. 현장의 분위기와 각자의 팬심에 따른 모든 응원 방식을 지지합니다."

### ② 면책 문구 (Global Footer)

모든 페이지 하단에 고정하여 명확한 위치를 밝힙니다.

> "본 서비스는 팬이 만든 비영리 프로젝트이며, QWER 소속사와 어떠한 공식적 관계도 없습니다. 공식 응원법 외의 내용은 작성자의 개인적인 제안일 뿐이므로 자유롭게 참고해 주세요."
