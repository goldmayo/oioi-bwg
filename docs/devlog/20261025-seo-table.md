# SEO 운영 반영과 테이블 요구 정정

## 해결하려던 문제

공개 메타데이터 오류를 고치고 사용자 제공 테이블 예제를 공용 UI로 수용할 필요가 있었다.

## 진행과 결정

SEO·Sentry 감사·초기 테이블을 순서대로 통합해 Promotion #253으로 배포했다. 이후 두 기능만 수용한 판단이 요구와 다름을 확인하고 15개 기능·compound 구조·Button 주입으로 수정했다.

## 시행착오와 회고

공용 패키지의 지원 기능과 한 화면이 사용하는 기능을 혼동한 것이 원인이었다. 데모의 모든 기능을 각 제품에 강제하지 않는다는 문장을 공용 지원을 줄이는 근거로 쓰면 안 된다.

## 검증과 한계

SEO 운영 관측은 #253 source 기준이다. 이후 4a517def의 15개 기능 수정은 통합 완료이며 해당 결과 문서에 운영 배포 미실행으로 기록돼 있다. 검색 순위 개선까지 검증했다고 쓰지 않는다.

이 글은 블로그 초안용 소급 기록이며 새 검증 결과나 당시 기록에 없는 동기를 만들어 넣지 않았다.
