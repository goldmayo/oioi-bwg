# 앱 분리와 MFA를 단계적으로 연결

## 해결하려던 문제

공개 서비스와 관리 기능을 나누되 기존 편집기·URL·권한 동작을 유지해야 했다.

## 진행과 결정

P01 파일 이동 → P02 workspace 검사 → P03 공통 계약/server → P04 Console 이관 → P05 MFA 순서로 진행했다. 공유 코드 추출의 기준은 실제 consumer였다.

## 시행착오와 회고

리뷰에서 재편집 폼 초기값·영상 ticker 수명·401 재인증 중 draft 보존 문제가 드러났다. MFA는 UI 단계 수가 아니라 최종 인증과 원자 OTP 소모·version 회수가 경계를 만든다.

## 검증과 한계

P01~P05 구현 완료가 Console 공개나 운영 전환 완료를 뜻하지 않았다. 이 글은 기존 결과의 검증을 요약하며 새 테스트 실행을 주장하지 않는다.

이 글은 블로그 초안용 소급 기록이며 새 검증 결과나 당시 기록에 없는 동기를 만들어 넣지 않았다.
