# MVP 편집기와 첫 배포

## 해결하려던 문제

가사 시작 시각과 강조를 직접 편집하고 YouTube 재생과 함께 보여 주는 기능을 먼저 만들었다. 초기 작업에는 광고 감지·응원 청크·키보드 조작도 포함됐다.

## 진행과 결정

3월 7일 vinext·Drizzle 전환 뒤 Cloudflare Workers와 Hyperdrive 연결을 조정했다. 3월 9일 배포 수정과 3월 11일 트러블슈팅 문서가 남아 있다. 기존 글의 파일명 날짜와 실제 문서 커밋 날짜를 구분한다.

## 시행착오와 회고

개발 서버에서 쿼리가 된다는 사실만으로 Workers 연결 수명까지 검증된 것은 아니었다. 당시 해결책을 현재 OCI Node runtime의 규칙으로 일반화하지 않는다.

## 검증과 한계

기존 글에 기록된 시행착오를 참고하되 이 정리에서 재실행하지 않았다. 당시 주장과 현재 공식 권장 사항을 재검증한 글은 아니다.

이 글은 블로그 초안용 소급 기록이며 새 검증 결과나 당시 기록에 없는 동기를 만들어 넣지 않았다.
