# 두 앱 검증에서 www 전환 완료까지

## 해결하려던 문제

이미지 빌드 성공 뒤에도 metadata 차단·권한·HTTPS·MFA 회수·옛 경로 종료를 실제로 확인해야 했다.

## 진행과 결정

P06 A/B에서 이미지·후보·공동 복구, C/D에서 Console HTTPS·실물 인증, E에서 Web 관리·일반 인증 종료, F에서 www 전환과 옛 Worker·staging·preview 종료를 완료했다.

## 시행착오와 회고

E의 초기 완료 보고는 일반 로그인 제거 요구를 반영하면서 철회·보완됐다. 배포 이력 충돌은 파일 tree를 유지하는 연결로 해결하고 merge 설정을 원복했다. 긴 작업을 한 번의 성공으로 압축하면 이 차이가 사라진다.

## 검증과 한계

기존 DB·MFA·R2/assets를 보존했고 추가 장기 부하·전체 관리자 자동 E2E는 이번 종료 범위가 아니었다. P06-G와 P07~P10은 별도 후속이다.

이 글은 블로그 초안용 소급 기록이며 새 검증 결과나 당시 기록에 없는 동기를 만들어 넣지 않았다.
