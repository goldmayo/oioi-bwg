# UI·UX 디자인 원칙

어이어이바위게의 공개 웹과 Console에서 화면을 구성하고 움직임을 결정할 때 쓰는 기준이다. 제품 화면을 설계하거나 리뷰하는 사람이 관리한다. 검증을 거쳐 채택한 규칙과 예외가 바뀔 때 갱신한다. 서비스 태도와 말투는 [서비스 철학](PHILOSOPHY.md), 상태의 정의와 전이는 [도메인 명세](migration/DOMAIN_SPECIFICATION.md), 구현과 접근성 검증은 [프런트엔드 아키텍처](migration/oioi-bwg-architecture-clean-v1/02-frontend-architecture.md)를 따른다.

## 디자인 철학

- 공개 웹은 팬이 자기 방식으로 응원에 합류하도록 돕는다. 재생 화면에서는 지금 읽을 줄과 참여할 부분에 가장 높은 시각적 우선순위를 준다.
- Console은 관리자가 대상을 빨리 찾고 작업 결과를 정확히 이해하도록 돕는다. 목록에서는 곡명·공연 모드·출처·공개 상태의 위치를 일관되게 유지한다. 편집과 공개는 각각의 결과가 드러나는 이름과 상태로 안내한다.
- 사용자가 작업을 이어갈 수 있게 현재 위치, 입력한 내용, 적용한 조건을 보존한다. 저장에 실패하면 원인과 다음 행동을 알리고 고칠 수 있는 위치를 연결한다.

## 시각 문법

- 반복해서 읽는 목록은 열 정렬과 일정한 행 간격으로 정보를 비교하기 쉽게 만든다. 곡명을 먼저 읽히게 하고 앨범명은 보조 정보로 배치한다. 긴 한글 제목과 좁은 화면에서 줄바꿈·말줄임을 확인한다.
- 제목, 검색, 필터, 결과는 한 흐름으로 읽혀야 한다. 데스크톱 목록에서는 기존 인라인 컨트롤을 사용한다. 모바일 상세 필터는 하단 시트에서 초안을 편집하고 **적용**을 누를 때 반영한다. 닫기와 뒤로가기는 초안을 취소한다. 모바일 카드의 정보 구조는 별도 설계에서 정한다.
- 표, 카드, 상세 패널은 맡은 정보에 맞춰 배치한다. 표는 행 사이의 얇은 구분선으로 비교를 돕는다. 카드와 고정 속성 영역은 표면색과 여백으로 묶는다. 옆에서 계속 참조해야 하는 속성은 넓은 화면의 본문 옆에 둘 수 있다.
- 작업 영역은 셸 위에서 한 겹으로 읽히게 한다. 배경, 작업 영역, 고정 패널은 작은 밝기 차와 경계선으로 구분한다. 시트·메뉴·대화상자처럼 기존 화면 위에 겹치는 요소에만 방향과 강도가 있는 그림자를 쓴다. 고정 카드, 표, 입력창은 평면을 기본으로 한다. 초점·선택·오류의 식별에는 테두리, 텍스트, 아이콘을 사용한다.
- 다크와 라이트에서 동일한 시각적 우선순위를 유지한다. 브랜드 색과 상태색의 쓰임을 구분하고, 색을 구분하기 어려운 환경에서도 선택과 상태를 알 수 있게 한다. 둥근 정도, 그림자 강도, 자간과 행 높이는 화면에서 역할을 비교한 결과로 정한다.

## 모션 문법

- 페이지와 패널을 전환할 때 사용자가 어디에서 왔고 어디로 돌아갈지 알 수 있게 한다. 시트는 연결된 화면 가장자리에서 들어오며, 닫으면 열었던 컨트롤로 초점을 돌린다. 애니메이션을 줄인 환경에서도 상태와 이동 경로를 이해할 수 있어야 한다.
- 버튼을 누른 순간 입력을 받았다는 신호를 준다. 저장, 공개, 데이터 갱신의 완료는 실제 작업 결과가 도착했을 때 표시한다. 오류는 필드 또는 관련 영역의 문구로 안내한다.
- 첫 로딩에 스켈레톤을 쓸 때는 최종 내용의 자리를 잡아 레이아웃 이동을 줄인다. 같은 조건의 재조회는 표시 중인 내용을 유지하면서 해당 영역의 진행 상태를 알려준다. 다른 조건의 응답을 기다리는 동안 이전 데이터를 보여준다면 그 데이터의 조건도 함께 표시한다.
- 성격을 드러내는 움직임은 반복 작업의 입력이나 읽기를 방해하지 않는 순간에 제한한다. 사용자 설정으로 모션을 줄여도 필요한 피드백은 남는다.

응원법 목록 시안은 동일 데이터와 기능에서 **Compact · Balanced · Expressive**의 타이포, 행 높이, 여백, 표면만 바꾼다. Balanced를 비교 기준으로 삼고, 첫 행의 위치, 읽히는 행 수, 긴 제목과 상태의 판독성을 다크·라이트에서 확인한다. 모션은 실제로 GA를 갱신하고 모바일 필터를 적용하거나 취소하면서 비교한다.

시그니처 후보는 공개 웹에서 팬이 응원 타이밍을 놓치지 않게 돕는 순간이다. 현재 줄 강조, 다음 응원 구간 예고, 수동 탐색 후 현재 위치 복귀를 같은 곡에서 조작해 본 뒤 채택을 결정한다. 채택한 시각·모션 규칙에는 선택 이유와 적용 범위, 예외를 기록하고, 이후 새 화면에서 같은 과업으로 일관성을 확인한다.
